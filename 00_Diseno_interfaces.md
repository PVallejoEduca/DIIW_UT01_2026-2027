# DIIW UT01: Planificación de interfaces gráficas

## Diseño de interfaces y productos digitales

El **diseño web** comprende la planificación, el diseño, la implementación y el mantenimiento de sitios web. No consiste solo en decidir su apariencia: también organiza el contenido, define cómo se mueve el usuario y garantiza que el producto cumpla su función.

Una **interfaz** es el punto de contacto entre una persona y un sistema digital. Su calidad determina si el usuario entiende las opciones disponibles, completa sus objetivos y recibe información clara sobre lo que está ocurriendo.

> Una buena interfaz debe poder entenderse sin necesidad de explicaciones adicionales.

## Productos digitales

Un producto digital es un producto no físico creado y distribuido mediante tecnología. Algunos ejemplos son:

* sitios y aplicaciones web;
* software y herramientas en línea;
* videojuegos en línea;
* libros electrónicos;
* archivos de audio y vídeo;
* cursos en línea;
* publicaciones digitales, como revistas y periódicos.

En esta unidad nos centramos en los **sitios web** y en las decisiones que permiten convertir una idea en una experiencia digital coherente y utilizable.

## Antes de diseñar

Un proyecto web debe partir de una definición clara de:

1. **Objetivos:** qué resultado persigue el sitio.
2. **Usuarios:** quiénes lo utilizarán y qué necesitan.
3. **Contenido:** qué información debe ofrecer.
4. **Funciones:** qué acciones podrá realizar el usuario.
5. **Características:** qué cualidades debe tener el producto.
6. **Restricciones técnicas:** dispositivos, navegadores, tecnologías y recursos disponibles.

Estas variables deben equilibrar tres perspectivas:

* las necesidades reales de los usuarios;
* los objetivos de negocio o de la organización;
* los requisitos y limitaciones técnicas.

## Forma, función y experiencia

Un sitio web eficaz transmite el mensaje previsto y ayuda al usuario a actuar. Para conseguirlo combina:

* **estética**, para crear una identidad visual apropiada;
* **usabilidad**, para que resulte sencillo de comprender y manejar;
* **funcionalidad**, para que las acciones y servicios funcionen correctamente;
* **accesibilidad**, para que pueda utilizarlo el mayor número posible de personas;
* **adaptabilidad**, para responder a diferentes dispositivos y tamaños de pantalla.

La apariencia nunca debe ocultar el propósito. Cada color, tipografía, imagen, espacio y componente necesita una función dentro del sistema.
